# Dashboard Module

This directory contains the web dashboard files for the Fire Fighting Humanoid Robot project.

Key files:
- firebot_updated.html: Updated dashboard interface with live camera feed, robot status, sensor data, control panel, detection history, and system logs.
- Backend: `src/api_control.py` provides the `/sensor_data`, `/move` and `/control` endpoints this page calls.

The dashboard provides real-time monitoring and control capabilities for the robot.
