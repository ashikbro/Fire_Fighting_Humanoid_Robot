# Automation Module

This directory contains code related to the automation and control of the Fire Fighting Humanoid Robot. It includes modules for actuator control, navigation, sensor management, simulation, and task scheduling.

Key files:
- actuator_control.py: Controls actuators of the robot.
- navigation.py, navigation_enhanced.py, navigation_rl.py: Different navigation algorithms.
- sensor_manager.py, sensor_fusion.py: Sensor data management and fusion.
- robot_controller.py: Main robot control logic.
- simulation_framework.py: Simulation environment for testing.
- task_scheduler.py: Scheduling tasks for the robot.
- test_navigation_slam.py: Tests for navigation and SLAM modules.

This module is essential for robot operation and should be maintained carefully.
